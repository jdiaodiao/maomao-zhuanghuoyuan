# 猫猫装货员 · 第一章「CatMart 超市装货员」设计文档

## 一句话
第一人称（只有两只猫爪）站在 CatMart 收银台的打包区，上游收银猫扫描过的商品沿传送带送来，
玩家按顾客要求把商品物理地装进指定数量/尺寸的塑料袋或方形纸袋，
根据**重心平衡、袋子规格、商品是否压坏**结算工钱。

## 已确认的机制决策
| 项目 | 决定 |
|---|---|
| 放置方式 | 物理自由抓放：猫爪抓起商品、旋转、松开后真实物理掉落/堆叠 |
| 节奏 | 真实收银台：传送带持续送货，光电传感器被挡住时整条带子停；顾客有耐心值 |
| 尖锐物品 | 尖锐度放大接触压力，扎坏软商品；会刺破塑料袋，纸袋更耐扎 |
| 工钱 | 订单商品总价 × 提成比例(10%) × 评分倍率；压坏的商品按原价从工钱里扣 |

## 商品系统（`Assets/Scripts/Items`）
每件商品由若干**部件(Part)**组成，每个部件有：
- 形状（盒/圆柱/球/锥）、尺寸、颜色
- **承压 Crush(N)**：持续受到来自上方/侧面其他商品的力超过此值 0.2 秒即压坏
- **抗摔 Impact(N·s)**：单次碰撞冲量超过即摔坏（鸡蛋、玻璃瓶、灯泡）
- **尖锐度 Sharp(0~1)**：碰到别的商品时把压力放大 (1 + 3×Sharp) 倍；刺破袋子
- **损坏样式**：Crumple 皱缩 / Dent 凹陷 / Squish 压扁 / Bruise 磕伤 / Leak 漏液 / Shatter 碎裂

商品整体有质量、自定义**重心偏移**（如洗衣液液体偏下、菠萝偏下）、是否大件（放推车不装袋）。
损坏后的模型由程序对网格做形变 + 变色 + 碎片/液体水洼生成。目前 82 件商品，见 `ItemCatalog.cs`。

**不能倒（Upright）**：生日蛋糕、插花、甜甜圈、草莓盒。倾斜超过 50° 持续 0.25 秒就算"倒了"（扶起来也不算数），
结算时总倍率每件 ×0.75（最低 ×0.4）。倾斜超过 25° 时光边红色闪烁、悬停提示"歪了，快扶正"。

**属性光边**：每件商品外侧一圈细光边（屏幕空间描边，`ItemOutlines` + `ItemOutline.shader`），颜色和悬停说明里的字一致：
| 颜色 | 属性 | 判定 |
|---|---|---|
| 白 | 普通 | 没有下面任何一项 |
| 黄 #FFD84D | 怕压 | 最弱部件承压 < 100N（< 30N 显示"极易压坏"） |
| 粉 #FF7FB6 | 易摔碎 | 有抗摔上限（鸡蛋、玻璃瓶、灯泡…） |
| 橙 #FF8A3D | 尖锐 | 尖锐度 ≥ 0.3 |
| 蓝 #6FC3FF | 大件 | 放推车 |
| 绿 #5FE08A | 不能倒 | 见上 |

多种属性时光边每 1.1 秒轮换一种颜色。损坏的商品光边变灰。
`GameManager.TraitHints = false` 时光边和悬停属性说明都不显示（给"靠记忆"的关卡用，见 Backlog）。

## 袋子
| 规格 | 内尺寸 宽×高×深 (cm) | 承重 |
|---|---|---|
| 小号纸袋 | 18×22×12 | 5 kg |
| 中号纸袋 | 28×30×17 | 9 kg |
| 大号纸袋 | 32×40×20 | 12 kg |
| 小号塑料袋 | 24×24×14 | 4 kg |
| 中号塑料袋 | 30×34×18 | 7 kg |
| 大号塑料袋 | 36×40×22 | 10 kg |

塑料袋：尖锐度 ≥0.4 的商品持续压在袋壁上（力×尖锐度 > 6N）会刺破。纸袋：尖锐度 ≥0.8 且 > 40N 才破。
超重的袋子在顾客提起时会破。

## 结算公式
```
基础工钱 = 订单商品总价 × 10%
倍率 = 规格系数 × 平衡系数 × 耐心系数 × 漏装系数 × 翻倒系数
  规格系数：完全符合 1.2；数量/尺寸不对 0.8；材质不对 0.6
  平衡系数：每袋重心水平偏移比 r（偏移/半宽）
           r≤0.15 → 1.3；0.15~0.3 → 1.3→1.0；0.3~0.6 → 1.0→0.6；>0.6 → 0.5
           刺破 0.5，超重 0.4；按袋内重量加权平均
  耐心系数：耐心 ≥50% 为 1.0，否则线性降到 0.7
  漏装系数：每漏一件 ×0.9（大件放推车不算漏装）
  翻倒系数：每件倒过的"不能倒"商品 ×0.75，最低 0.4
实得 = 基础工钱 × 倍率 − 压坏商品原价之和   （可以为负：倒赔）
```

## 场景布局（米）
- 柜台高 0.9；打包台 x∈[-0.875,0.875]，4 个袋位
- 传送带 x∈[-4.3,-0.9]，从左往右送，末端有光电传感器
- 右侧袋架（6 种袋子），右前方猫铃 = 完成订单
- 对面：顾客猫 + 购物车（大件放这里）
- 左侧远处：上游扫描台 + 收银猫

## 操作
| 按键 | 功能 |
|---|---|
| 鼠标 | 看 |
| WASD | 小范围移动 |
| 左键按住 | 抓起商品 / 点袋架取袋 / 点铃结束订单 |
| 滚轮 | 调整抓取距离 |
| Q/E、R/F | 旋转手中商品（水平/俯仰） |
| Z | 手中商品回正 |
| X | 移除看着的空袋子 |
| Tab | 查看小票 |
| B | 显示/隐藏袋内重心标记 |
| Enter | 完成订单 |
| V | 俯视装袋模式（鼠标直接拿放，WASD 平移，滚轮缩放/抬高，1-4 跳到袋位，V/Esc 返回）|
| Esc | 释放鼠标 |

## 后续可扩展
- 用正式美术模型替换程序化部件（保持 PartDef 数据即可）
- 顾客特殊要求（冷冻品单独装、鸡蛋放最上面）
- 一天结束的评级、升级（更大的手、更慢的传送带）

## 美术管线（生产级程序化建模）
全部资产由代码生成，无外部模型文件；外观与物理碰撞体分离（碰撞仍是 ItemCatalog 里的简化部件）。

| 模块 | 文件 | 说明 |
|---|---|---|
| 网格工具 | `Core/Gfx/MeshKit.cs` | 圆角盒、旋转体（瓶/罐/杯）、枕形包装袋、管道、变形球、多边形挤出；按材质合并子网格 |
| SDF 雕刻 | `Core/Gfx/Sdf.cs` | 平滑并集/差集 + Surface Nets，用于猫、猫爪、面包、蛋盒、带把手的桶、小熊蜂蜜瓶等 |
| 程序贴图 | `Core/Gfx/TexGen.cs` | 纸板、牛皮纸、拉丝不锈钢、橡胶皮带、水磨石地砖、毛发、果皮（苹果/香蕉/西瓜/菠萝…）、肉、三文鱼、网袋等，含法线贴图 |
| 包装印刷 | `Core/Gfx/LabelBaker.cs` | 离屏相机把品牌横幅、标题、图标、底纹、营养成分表、条形码渲染成贴图；按真实尺寸排版 |
| 商品外观 | `Items/Looks/*.cs` | 82 件商品逐一建模（纸盒、包装袋、罐头、玻璃瓶+液体、托盘肉+保鲜膜、透明盒烘焙、网袋果蔬…） |
| 场景 | `Store/StoreBuilder.cs` | 不锈钢台面、木纹面板、橡胶传送带+滚筒、扫描塔、POS 机、镀铬钢丝购物车、陈列真实商品的货架、冷柜、灯箱招牌 |
| 角色 | `Store/CatBuilder.cs`、`Player/PawRig.cs` | SDF 猫（毛发、白肚皮、粉鼻子、眼睛高光、胡须、眨眼、呼吸）、橘猫第一人称爪子（白袜子 + 粉肉垫） |

材质模板放在 `Resources/CatMart/*.mat`（标准/法线/玻璃/镂空/自发光/无光照），保证打包时着色器变体不被剔除；
新增材质类型时，在 `CatMart → 重建材质模板` 里加。
