# 待办 · 之后要解决的大问题

记录于 2026-11-24，按讨论顺序，暂不处理。

## 1. 物品的旋转自由度和控制方式
- 现状：Q/E 水平转、R/F 前后翻、C 侧放 90°、Z 回正；旋转是相对视角的连续转动。
- 要想清楚：需要几个自由度？要不要吸附到 90° 档位？用鼠标拖拽旋转还是按键？俯视和第一人称是否用同一套？

## 2. 猫手的伸缩，以及拿东西时应该是什么样
- 现状：右爪只是向商品顶部插值移动，商品用"有上限的弹簧力"悬浮在目标点，没有真正"握住"的样子。
- 要想清楚：爪子伸出/缩回的距离与动画；单手还是双手托住大件；手和商品的接触点；俯视模式下手是否可见。

## 3. 物品、猫猫角色、场景的建模 —— 考虑使用素材库
- 现状：全部程序化生成（见 GDD「美术管线」）。
- 方向：评估素材库（如 Kenney、Quaternius、Poly Haven 等 CC0，或付费的 Unity Asset Store 资源），
  对比风格统一性、覆盖率、授权；保持 PartDef 物理数据不变，只替换外观层（ItemLooks / CatBuilder / StoreBuilder）。
